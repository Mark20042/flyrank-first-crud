# To-Do List CRUD API (W2 · A1)

A clean, RESTful to-do list API built as part of the AI Fluency backend curriculum using **Node.js & Express**. Manages an in-memory task collection through standard HTTP verbs with input validation, explicit status codes, and interactive Swagger UI documentation.

## 🚀 How to Run

### Prerequisites
- Node.js installed (`node -v` to check)

### Setup & Execution
```bash
# 1. Install dependencies (express, swagger-ui-express)
npm install

# 2. Start the server
npm start
